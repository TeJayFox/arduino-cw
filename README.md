## Setup
1. Download Arduino IDE
2. Download zip file and open INO file in Arduino IDE
3. Connect LCD Screen to PC port and select Arduino Uno board
4. Type BEGIN in the serial monitor and then type other commands to setup employees

## What does it do?
- The program stores information about different employees on an LCD screen
- It shows how much information is free and therefore how many more employees can be stored on the system
- Commands can be ran on the PC console to add or update employee information
- Error checking is used to prevent misuse of the system
